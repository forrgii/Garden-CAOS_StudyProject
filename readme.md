# Умные цветы (Smart Flowers)

Симуляция клумбы с умными цветами и садовниками.  
Индивидуальное задание №1 по дисциплине «Архитектура компьютера и операционные системы».  
**Вариант 14** — «Задача об умных цветах».

Программа моделирует клумбу: каждый цветок самостоятельно отслеживает
влажность, увядает и создаёт заявку на полив. Два садовника обслуживают
заявки; повторный полив до истечения защитного интервала приводит к
гибели растения от перелива.

---

## Зависимости

- **Linux** (или WSL 2 на Windows)
- **GCC** 9.0+ (C11)
- **GNU Make** 4.0+
- **libc** (POSIX)

Опционально: `gdb` (отладка), `valgrind` (проверка утечек).

```bash
sudo apt install build-essential gdb valgrind
```

## Архитектура

Программа состоит из трёх модулей:

| Модуль | Ответственность |
|--------|-----------------|
| `smart_flowers` | Сущности `Flower` и `Gardener`, их состояния, инициализация, поиск заявок |
| `logger` | Дублирование вывода в stdout и в лог-файл через `open`/`write`/`close` |
| `main` | Ввод параметров, главный цикл симуляции, обработка `SIGINT` |

**Состояния цветка:** `NORMAL → WILTING → WATERING → RECOVERING → NORMAL`,
а также `DRYING` и `DEAD` (засуха или перелив).

**Один такт** состоит из двух фаз:
1. обновление цветов (высыхание, пороги, заявки);
2. обновление садовников (поиск заявки, полив, проверка перелива).

## Быстрый старт

```bash
make                # debug-сборка
make run-args       # запуск: 15 цветов, 3 садовника, 300 тактов
make run            # интерактивный ввод параметров
```

Аргументы командной строки: `./smart_flowers <цветов> <садовников> <тактов>`.

Прерывание — `Ctrl+C`, выводится итоговая статистика.
